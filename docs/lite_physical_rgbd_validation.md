- WoundAI3D `scripts/phantom_validation/phantom_validation_analyzer.py` 的欄位是 R-G 距離、ΔE、微凸點高度、mesh hole ratio、export success，沒有 Lite surface_cm2。不能將 Lite 面積塞入其他欄位或繼承其 pass/fail。

## 使用者確認的角度驗收範圍（2026-10-04）

以正對及建議操作角度內的表現作主要驗收，大角度作限制案例；不要求所有角度同等準確，也不為43°單筆結果強制重做整套驗證。傾角超過25°提醒分割邊界與面積誤差可能增加，在既有深度品質閘通過時仍顯示参考值；10–25°建議正對及核對邊界，不聲稱角度影響可忽略。25°是操作提醒閾值，未被證明為±某百分比的精度分界。正對及建議角度內的可接受誤差須依該版本及相同面積指標的證據確認。43°的+11.34%保留在限制紀錄，不移除、不歸因於手動改遮罩，也不據此宣稱建議範圍已不合格。

## 擴充階段：24 次受控平面量測

使用兩個沒有個資的實體、霧面、高對比目標：不對稱 L 形及非方形矩形。直接拍攝實物，不翻拍螢幕。目標不要遮住可觀察的邊界；標示各邊長和量測工具的最小刻度，記錄尺寸的不確定度。先用實際量測邊長算參考面積，不用印表機預設尺寸充當真值。

矩陣：2 目標 × 2 手機方向（直、橫）× 2 距離（25、35 cm）× 3 次獨立重新取景 = 24 筆。光照與目標固定，鏡頭盡量正對平面；每次放下再重新取景，不能把同一 frame 重算當三次拍摄。

這一批是定位錯配與重複性的最小工程試驗，不足以推論所有傷口、機型、角度、膚色或光線。初步發現問題先修正並另立新 cycle，保留失敗資料，不挑選最接近參考值的結果。

每個 frame 先以人工圈選已知邊界量測，以降低 AI 分割誤差的混入。另存 AI 原始輪廓與人工輪廓供分開比較，不能覆寫成只有最終一份。AI 在幾何目標上沒有圈出傷口屬預期可能情境，不應把它當患者影像精度結果。

保存每個 frame 的原始本機深度、配對 RGB、雲端衍生 PNG、內參與其參考尺寸、方向轉換、App build、演算法版本、record/image/revision 對應。未提供的感測器信心值、曝光時間或 pose 明記 unavailable，不能填 255、接收時間、identity matrix 冒充。

## 比對順序及結果

1. 完整性：逐檔 SHA-256；PNG 完整解碼；尺寸、單位、內參參考空間；拒絕尚未確認的最終修訂。此項不能替代幾何精度。
2. 同 frame 往返：本機原始深度重算，對照保存重載；雲端毫米 PNG 另算並量化量化誤差，不能要求與 Float32 位元相同。保持相同遮罩及算法版本。
3. 空間對齊：疊合不對稱目標角點，檢查左右／上下翻轉與旋轉。平面彩色邊界本身不一定有深度邊緣；再以已知厚度階梯實物觀察深度不連續位置，不能只靠平面 RGB 角點證明深度配準。
4. 面積：signed error = estimate − reference；relative error = signed error / reference × 100%。分別報表面積及投影面積，列每筆、平均偏差、絕對誤差、最大值、分方向／距離的重複性。參考值必須 > 0，缺失不填 0，失敗拍攝也計入嘗試數。
5. 同一目標直橫拍：先比較組別誤差，再檢查是否有系統性方向偏差。不同目標或不同縮放螢幕照片不可組成同傷口趨勢。

本輪不預設「95% 精確率」或把合成測試 3% 容許差轉成實拍保證。先取得完整試驗資料及參考不確定度，再事先凍結下一批的工程目標與獨立驗證集；不得事後調整門檻讓同一批數據過關。尚未取得這些結果前，使用者說明維持「參考估算，實拍誤差範圍尚未建立」。

## 第二階段：曲面及獨立 WoundAI3D

加入可獨立取得面積／高度參照的階梯和曲面模型；參考方法及不確定度先記錄，再擴展角度、光照、操作人和裝置。沒有可追溯的曲面面積參照時，不產生曲面 accuracy pass。

資料拆分以實體目標／傷口／拍攝 session 為單位，衍生裁切和修訂留在同一組，不能分散到訓練與驗證。安裝碼不是自然人識別，不能宣稱跨安裝同人隔離。Lite 個人圈選是 user annotation，不是醫師真值。

交付 WoundAI3D 前仍需版本化、可撤回的 manifest：來源分類、同意版本與用途、撤回查驗時間、資產 digest、最後修訂及其回執、方向／內參／單位、資料轉換沿革、允許的研究用途。傳輸測試照片標 test_only；經過預檢不等於研究授權。Native Float32 雲端保存與完整 manifest 尚未實作，不補造缺欄位。
