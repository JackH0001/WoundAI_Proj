# 確認上傳與行政結果同步輸出驗證 — 2026-10-14

基底 dc7165c3e5f2b148cb7c8c9d05c763d5d3349c00，分支 codex/mmh-full-alignment-20261013。接續 stable-entry.patch 在內的十一份凍結 patch；本輪為本機候選修改，未提交、推送、部署或更新商店／實機 App。

## 行為

iOS 與 Android 的機構／示範醫療 runtime 共用確認送件觸發點：研究工作成功加入持久待傳佇列後，以該份已確認紀錄與已保存影像／原生遮罩產生行政副本。取消拍攝、單純存入時間軸、修改後尚未確認上傳均不再自動輸出。兩個結果分別顯示：副本產生／指定資料夾交付，不代表研究資料已獲雲端保存收據。

相同快照的加密私密副本依內容去重；修改標註或分數後重新確認送出會建立另一版，保留舊版。自動網路重試只處理研究待傳，不再觸發行政輸出。使用者另一次明確提交可再次交付到自訂資料夾，不覆寫已交付的歷史資料夾。

設定預設關閉；開啟後預設保存於 App 加密且排除系統備份的私密空間。兩端可透過系統資料夾選擇器選擇目的地，iOS 儲存 security-scoped bookmark，Android 使用持續 SAF 授權；設定按環境隔離。自訂目的地建立新修訂資料夾，寫入並讀回核對後才結束暫存狀態。失去資料夾權限時顯示輸出失敗，保留私密副本及研究待傳，不能悄悄換到其他共享資料夾。目的地可能自行同步，設定與手冊已提示。

兩端输出包含本機保存的量測影像、結果疊圖、面積／分數及最終傷口／組織 PNG；iOS 另保存送件 JSON。檔名及包裝沿用平台既有格式，尚非完全相同的跨平台行政匯出 schema。iOS 嚴格比對快照與送件 payload 的影像關聯、尺寸、輪廓、組織比例、面積、滲液與原生遮罩。Android 驗證輸出資產與實際後端 encoder 送出值一致。

## 尚待驗收／限制

- 需在 iPhone 與 Android 實機驗證系統資料夾選擇、重啟後沿用授權、目標供應商寫入及取消權限；本輪不宣稱真實 File Provider／SAF 交付全面驗收。
- 自訂資料夾輸出與研究上傳為兩項工作，沒有跨雲端及文件供應商的原子交易。程序於副本建立前被終止時需使用者重試輸出；行政輸出本輪尚無独立持久背景重試佇列。
- 保留的是當筆 App 已保存的工作影像 bytes；本輪未增加原始感測器全解析度 JPEG 採集或保存。不能把行政疊圖包宣稱為全解析度攝影原檔、完整3D研究包或已整合PACS。
- 醫療原生傷口／組織雙遮罩與後端新契約仍須成對部署，穩定入口及雲端收據／讀回仍待新版本實機驗收。
- 後續示範與機構版沿用此流程；僅以建置／機構設定控制入口、權限與輸出選項。WoundLite 維持民眾流程，不能等同醫師組織精標。
