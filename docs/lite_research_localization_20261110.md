# Lite 研究選擇、撤回與額度顯示：中英文驗收

此變更只處理呈現。研究資料收案、個人辨識、撤回、重新同意與額度仍使用既有契約；
不改同意書／揭露版本、不改研究偏好、佇列、回執、安裝身分或原始照片／深度。
英文不是新的研究同意，也不代表已取得 IRB、法規或全球上市核准。

## 修正前後

- 之前研究同意、設定中的撤回說明及額度頁仍固定繁中。現在以裝置語系呈現 134 組研究文字，
  共用設定／服務按鈕沿用 `LiteService`，找不到的訊息保留原文，不臆測為成功。
- 候選個人服務版明確說明：拒絕研究仍可使用個人服務；研究只傳符合既有條件的資料。
  一般版仍依原設定顯示離線手動圈選選項，沒有以翻譯偷換方案。
- 保留完整深度圖、相機參數、圈選外距離、同一安裝的歷次連結、原始 AI 與後續修訂遮罩的揭露。
  拒絕、重新加入及刪帳連帶撤回的原條件未改。
- 「目前可見媒體清除」與歷史版本、備份、研究衍生資料尚待核對仍分開。
  重新加入只適用之後新拍攝，不會自動補送舊佇列或恢復已清除資料。
- 個人每日免費 2／Plus 共 10 次、同時 1／5 處，與研究安裝額度保持分流；日期只改顯示語系。

## 驗證與邊界

普通及個人服務候選 Release 各 603 項通過、0 失敗、1 項既有模擬器檔案保護限制略過。
新增 8 項已包含其中，兩配置互有重疊，不相加為獨立案例。Xcode 27.2，iOS 26.2 模擬器。
新增測試涵蓋：套件資源／格式參數、完整資料揭露、方案分離、重新加入範圍、部分清理說明、
撤回檔案逐位元不變且零傳送呼叫、研究／個人額度的原身分與到期防護，以及未知錯誤保留。

UI 只用空白合成環境，不登入、不拍攝、不購買或送出研究資料。
最初在先前單元測試使用的模擬器執行時，研究開關因既有撤回狀態停用，兩輪各 2 項未通過。
保留原狀態和失敗證據，改用新建模擬器；測試明確拒絕把既有撤回重設成未同意。
點擊使用開關實際位置，沿用既有 UI 測試方式。
