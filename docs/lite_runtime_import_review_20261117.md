# 營運材料首次匯入：角色定義核對補強

## 修正前後

原固定方案包含 `iam_review_sha256`，但匯入器只重新讀取角色、檢查敏感權限是否
仍限本人，沒有實際比對此欄位。角色定義即使已偏離核准快照，仍可能通過檢查。

現在依角色名稱收集完整定義並核對固定雜湊；即使改動後仍是本人專用、或只變動
非敏感權限，也會停止。讀完角色後再次讀回專案 IAM，避免接受期間已觀察到的綁定變更。
檢查適用於第一次新增、後續角色新增、最後核對及中斷恢復。

這是分開讀取不同資源，不是跨資源原子鎖。通過檢查後仍可能發生並行管理操作；
執行窗口須避免其他 IAM／角色變更。若恢復時定義已變，不能自動接受新設定：
保留日誌並明列未確認角色，由操作員重新審閱後提出受限恢復方案。
