## 已實作

- 待傳工作存在每個環境獨立的 noBackupFilesDir，Keystore AES-GCM 加密、AtomicFile 原子保存，無帳密或登入 token。跨環境檔案即使被複製也拒讀。
- 明確入列要求：已存紀錄、醫師確認、影像綁定、溯源、完整 raster 與已知組織修改基準。入列前後再次核對已存紀錄和影像／raster 位元組，以及呼叫端提供的即時權限。
- 固定服务網址、設定帳號、送件 actor、紀錄 JSON（Date 保留毫秒）、影像 SHA、raster 位元組及原生傷口／組織 PNG SHA。同一工作不因重啟而重建另一份；不同服務或帳號不得繼承。
- 跨實例序列處理；網路前先落盤 attempts 與退避時間。逾時、HTTP 408／429／5xx 可重試；驗證或收據異常暫停，需明確恢復。退避由 60 秒增加，最高 1 小時。
- 驗證回覆的 code、image_id、修訂收據、兩張遮罩 SHA 與 mask contract；HTTP 200 本身不算保存成功。只保留已驗證的收據欄位，不落盤任意錯誤回覆。
- 先持久保存收據，再呼叫本機修訂 CAS 確認。若本機更新失敗，恢復後沿用收據；新修訂已存在時，不把它標成舊修訂已上傳。
- 權限 WAIT 暫停；REVOKED 終止，保留已收到的收據。取消不吞掉例外；已落盤工作留待恢復。檔案損毀停止讀取／入列，不略過或刪除待傳資料。

本層不添加 MMH 資料來源分級。Permission 是必須由正式 runtime 依最新身份、環境與同意提供的安全邊界，不是常數 ALLOW 的產品預設。
