# 容量等待與研究續傳驗證 — 2026-10-17

## 本次交付範圍

MMH iOS 39、Android 31 的已確認研究送件，以及 WoundLite 已綁定影像的修訂與撤回。這是待傳可靠性修正，不是已測得的伺服器吞吐量提升。

- 429／503 保留 `Retry-After` 秒數、HTTP 日期（採伺服器 Date 修正時鐘偏差）與數值 `retry_after`；採最長期限、至少 60 秒並加少量隨機延遲。重啟或手動連按均不能提早重送。
- 等待期限只改傳輸排程，不改影像、輪廓／組織遮罩、面積、採集時間、深度或修訂內容。已確認標註而原始深度未確認時，只接續深度；回覆遺失以原修訂及相同位元組核對。
- iOS／Android 前景每 5 秒檢查本機待辦，未到期限不發送網路請求。App 被系統暫停或關閉後，在重新開啟時接續，不能保證關閉期間仍執行。
- Android 登入／session 核對遇到忙碌也保存期限，避免等待傳輸前反覆驗證。相同紀錄的較新修訂不能超越尚未確認的舊修訂。
- 醫療版撤回／恢復須取得 HTTP 200、正確狀態及相同代碼的收據；僅 HTTP 成功、登入 HTML、不同代碼或相反動作都不算完成。未確認的撤回保留待辦。
- Lite 撤回的 202 代表待完成，會保留下一次核對期限；撤回期間保持禁止研究上傳。完成只代表已確認的 live media 範圍，不宣稱備份或既有模型已刪除。
- Lite 照片正規化後只編碼一次 JPEG，雲端傳送與本機 RGB-D 綁定沿用相同影像位元組。

## 相容性

不變更既有研究 payload schema、遮罩類別或深度座標契約。新增本機排程欄位可讀舊佇列。醫療版及 Lite 的 schema 本來不同，本次不以改標 schema 的方式假裝相同；依各自匯入器驗證。Android 未實作 LiDAR，不製造缺失的深度。3D 測試證明檔案／綁定相容，不代表深度數值精度已獲臨床驗證。
