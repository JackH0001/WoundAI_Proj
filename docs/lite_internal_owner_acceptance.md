# WoundAILite 本人內測的服務範圍

TestFlight 群組決定誰可以安裝 App。服務另外核對已簽章的安裝身分；個人服務也核對經 Apple 登入確認的帳號。這兩項限制僅供本人驗收期間使用。

| 設定 | 個人服務 | 研究服務 |
| --- | --- | --- |
| `LITE_INTERNAL_OWNER_MODE` | `owner-only` | `owner-only` |
| `LITE_INTERNAL_INSTALLATION_SHA256` | 該服務已登記安裝識別碼的 UTF-8 SHA-256 | 研究服務自己登記的識別碼，以相同方法計算 |
| `LITE_INTERNAL_ACCOUNT_SHA256` | 經核對的服務帳號摘要，與登入收據的 `account_sha256` 相同 | 不設定 |

由操作員從可信管理面核對本人與這些登記的關係，兩個服務分別設定；請保留核准記錄及設定版本。只提供部分設定會拒絕啟動。三項均未提供時沿用原服務行為。因此本人階段必須讀回修訂的實際設定，並對**同一個服務**使用兩台各自簽署有效請求的裝置測試。

本人應可登入、進行辨識、取得本人結果並送出已同意的研究資料。另一個有效安裝在新增研究資料、開始辨識或取得訂閱前應收到拒絕，且資料、額度與模型呼叫數不增加。指定裝置若改用另一個 Apple 身分，首次登入確認在交換授權碼、建立帳號與核發額度前即停止。裝置登記、驗證挑戰與防濫用計數保留原安全機制。

原有參與者仍可用原帳號重新登入、查看既有結果或收據、撤回研究及要求刪帳。接受原來的帳號只為保留既有權利；新增服務工作仍需本人資格。切換前用合成資料驗證這兩條路徑。公開或多人外測的資格與名單須另行規劃。
