# Lite 操作指南搜尋修正 — 2026-11-13

基準：92107a9。範圍僅本機指南、顯示與測試；未變更服務、研究同意、訂閱權益或原始資料。

## 問題與變更

原搜尋使用字串包含與固定主題順序。「取消自動續訂，保留照片」可能先出現拍攝；英文 fingerprint 命中 print，restore photos 也可能命中恢復購買。

- 英文關鍵詞改為完整詞／詞組比對，維持大小寫、全形與空白正規化；中文可不分詞，也容許 PDF／LiDAR 緊鄰中文。
- 明確操作優先於背景詞，再以詞組長度與命中數排序，同分沿用既有順序。其餘相符主題保留，不把結果當成唯一答案。
- 將 restore 限定為購買或訂閱詞組；補常見取景、模糊與取消續訂用語。
- 即使有關鍵詞命中，支援的裝置仍可由使用者主動選擇 AI 找其他主題。AI 不自動啟動，仍只顯示已核對的內建說明，不產生自由回答或執行帳戶操作。
- 中英文畫面說明搜尋不判斷病況、不代為取消訂閱或刪帳；未支援 AI 時可繼續離線閱讀所有主題。

排序是詞彙檢索，不是完整語意、否定句或醫療意圖分類器。

## 保留的失敗與工具修正

首次指定測試抓到 cancel my subscription 未識別，補取消用語後18項全過。候選完整套件首次因驗證工具共用一般版產物而連結失敗，改為獨立建置目錄後重跑。最初 UI seed 發現完整套件已留下「不同意研究」狀態，停止該輪；保留原測試容器，換另一個全新 UI App，未清除或改寫原選擇。這些失敗原始結果均保留。
