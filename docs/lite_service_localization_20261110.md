# Lite 個人服務中英文顯示 — 2026-11-10

本輪以 `8bd06ce08721f87b97a02bbe3118013522371f3d` 為基準，處理多語上市工作的第一段：
個人服務登入、裝置登記、訂閱／恢復購買、刪帳及相連的法律說明入口。新增 169 組
繁中／英文顯示文字；**不是全 App 英文化完成，也不是新的英文市場發布**。

## 行為與資料界線

原本服務畫面與狀態固定顯示繁中；現在依介面語言選擇英文或原繁中。其他語言先保留
繁中，不宣稱已有該語言翻譯。缺少的字串回傳原文，不生成猜測的狀態。

`LiteServiceCopy` 只在顯示時翻譯，沒有更動帳號 ID、Apple transaction／appAccountToken、
研究同意版本、日誌鍵值、收據格式、原照片、遮罩、深度或歷史紀錄。動態刪帳及登入
提示以暫存的片段組合；新的錯誤會取代先前已受理的摘要，不會因翻譯仍顯示成功。
資料處置計數仍來自同一份已驗證的收據，沒有新增清理或送件動作。

- 免費每日成功辨識 2 次；Plus 是每日**合計** 10 次，包含當日已用次數。
- 免費 1 處、Plus 每帳戶同時最多 5 處；結束追蹤可換，舊時間軸保留。
- Apple 回傳的當地價格作為不透明文字插入，不自行換匯或把 US$1.99 寫成通用售價。
- 登入不等於付款，也不開啟研究上傳；研究同意仍是獨立選擇。
- 刪帳同時要求撤回相連研究；不代表立即清完所有副本，也不等於取消 Apple 訂閱。
- 手機紀錄保留；原有存取限制及人工確認步驟保持一致。

## 驗證方法

新增 9 項單元測試，包含兩份字串表確實封裝、鍵及格式參數相符、業務文字語意、
Apple 價格原樣保留、未知內容不改寫、舊成功提示不遮蓋新錯誤、語言切換不改動
Codable 收據、以及真正的刪帳 store／journal 不因讀取英文提示而新增要求。

新增 1 項英文 UI 測試，與既有繁中服務入口測試一起執行；明確指定測試語言。
英文測試只開方案並確認尚未登入時沒有購買／恢復按鈕；繁中測試確認模擬器登記
失敗時提示仍正確、保留重試入口且不開購買。這是本機模擬器驗收，不能替代 Apple
Sandbox S0–S9、付款、恢復購買或雲端額度驗收。UI 內看見的模擬器商品價格也不作為
任何市場正式價格的證明。

本機結果與原始 XCTest summary／tree、畫面附件存於
`woundailite-service-localization-20261110` 覆核包；一般與候選 profile 的相同測試不可
相加當成不同案例。唯一允許的既有略過項是模擬器未回傳檔案保護類別。

本輪本機結果：一般 Release 與 Native Sandbox Release 各 588 項通過、0 失敗、1 項
上述既有略過；中英文 UI 2 項通過、0 略過。完整單元套件包含新增 9 項，不額外相加。
UI 附件已目視核對英文訂閱入口、價格格式及說明未截斷；測試沒有購買或刪除真實資料。
這一筆尚未推送，不能把基準 `8bd06ce` 的綠色 CI 計為新變更的 CI。

## 後續與限制

量測、歷史時間軸、PDF、操作指南、獨立研究同意／撤回頁及個人額度詳細頁仍有繁中
字串，須接續翻譯並驗收。隱私 HTML 原有中英文內容沒有重寫；本輪只翻譯其入口，
不表示政策已對外發布或各市場法規已完成核對。內部服務辨識驗收頁不在本段翻譯範圍。

沒有更動模型、AI 指南提示、後端、IAM、KMS、資料清理或商店版本；不重跑與本輪無關的
後端大套件。真實 Apple 操作、受限雲端初始化及外測授權依原計畫分別處理。
