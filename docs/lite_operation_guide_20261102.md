# WoundAILite 操作指南

在「設定 → 操作指南」可依主題閱讀，或輸入關鍵字搜尋。指南顯示當前 App 版本與實際選單路徑。一般版提供拍攝、面積品質、修邊、時間軸 PDF、追蹤及研究撤回說明。有個人服務的候選版另含額度、訂閱恢復、取消續訂與退款，以及帳號刪除。

未找到關鍵字時，支援 Apple 裝置端語言模型及繁體中文的手機可以自行選擇「使用裝置端 AI 找主題」。模型只接收限長的操作問題及該版本的主題清單。程式只接受清單裡的一個主題代碼，操作步驟一律來自 App 內建說明。機型或語言不支援、模型未就緒、無法分類及輸出不符時，仍可選取離線主題。不使用帳號、病歷、拍攝資料、電子郵件、聊天紀錄或雲端辨識額度。帳單連結由程式固定，使用者需自行點選。指南沒有執行帳號、訂閱、研究或傷口資料變更的入口。

驗收需分開記錄本機搜尋、畫面點按、模型是否可用及真機分類結果。退款問題應引導至 Apple 帳單支援；刪帳和研究撤回各有獨立的說明。臨床問題不得顯示模型產生的自由文字。外測僅使用合成問題及模擬標靶。
