# Lite 訂閱入口續接（本機候選，2026-11-04）

## 問題與結果

使用者在 TestFlight 44 看得到 Apple 月費，但未完成裝置登記與服務登入時，`LiteNativePurchaseView` 隱藏購買按鈕，僅保留文字說明；未登記時甚至沒有可直接接續的操作。此次在方案頁加入「登入並繼續訂閱 Plus」，由使用者點擊後依序核對既有裝置、必要時登記、Apple 登入，成功後留在同頁顯示原有含月費的訂閱／恢復購買操作。

登入入口不呼叫 purchase、restore、辨識或研究送件。真正購買仍須另外按含月費的訂閱按鈕，再由 Apple 確認；沒有用程式代替購買確認。未取得價格時不顯示可購買按鈕。

## 保護與復原

- 開頁或讀月費不會開始登記／登入。登入動作只由使用者明確點擊觸發。
- 已登記／已登入者沿用原資料；不重建身分、不重新購買。
- 讀不到舊登記時不建立新登記。連線、登入取消、登出競爭或刪帳要求會停在對應步驟，保留紀錄並提示本次未付款。
- 同時點擊採單一執行；正在購買、登記或身分操作時禁止再啟動。
- 未確認的登入／登出仍由既有帳號核對流程處理；不重送一次性 Apple 授權碼。
- 操作指南同步說明新流程，研究同意維持獨立。

## 驗證與限制

新增 8 個 XCTest：首次登記＋登入、重啟沿用、登記不可讀、離線、取消、連點、登入回應晚於登出、刪帳處理中。UI 驗收確認新入口可見且可操作，模擬器無法登記時顯示停止原因、保留重試入口，未出現購買按鈕。StoreKit 使用本機商品設定，沒有真實交易。

一般版與候選版 Release 各 570 項通過、1 項既有模擬器檔案保護測試略過；兩者包含相同測試，不加總。入口 UI 操作 1 項通過。首次執行的兩個失敗僅為提示文字預期不同（「也未付款」與「尚未付款」），統一提示後完整重跑通過，原失敗產物保留。完整測試結果及 xcresult 讀回在本輪本機覆核包。這是原始碼修正；不變更已交付 44 的簽署檔，不自動推送、部署或交付新 TestFlight。真正 Apple 登入／Sandbox 訂閱仍需候選後端與憑證準備完成後另行驗收，不能把本機測試算成已可訂閱。
