# Lite 研究參與者升級 App 後的撤回

已加入研究的人在 App 更新後仍應能用原安裝身分撤回，即使研究服務目前只接受舊版送出新工作。撤回時，iOS 使用原本保存在鑰匙圈的研究身分，要求用途為 `withdraw` 的 App Attest 挑戰，再簽署自己的 DELETE 請求。這條路徑沿用原本的收據、清理範圍和佇列防護。

## 候選服務設定

| 設定 | 允許的操作 |
| --- | --- |
| `WOUNDAI_LITE_ATTEST_VERSIONS` | 原有研究登記及各項研究操作，依既有帳號、研究同意與服務限制執行。 |
| `WOUNDAI_LITE_ATTEST_WITHDRAWAL_VERSIONS` | 選填。只接受已登記裝置用撤回專用挑戰，撤回自己原有的研究資料或指定同意期間的研究資料。最多 16 個額外組建。 |

候選方案產生器的 `--version 46 --withdrawal-version 60 --withdrawal-version 62` 會產生「一般研究操作 46、額外撤回 60 和 62」的設定，並把設定檔雜湊寫入方案。此處的數字是測試案例。部署時應依實際發給研究參與者的組建盤點兩份清單。一般操作與額外撤回清單重疊、重複或含萬用字元時，研究服務會拒絕啟動。未設選填欄位時維持原來的版本規則。

## 升級、回復與驗收

1. 先確認新修訂與預備回復修訂的映像都含此版本判定，讀回兩份設定及其摘要。較舊的映像可能忽略新增欄位。
2. 以既有合成安裝與實際預計支援的組建驗證一般權限及撤回權限。未列為一般版本的組建應能撤回，但新登記、上傳和重新同意應各自遭拒。原本獲准的一般版本保有原有操作。
3. 驗證參與者完成撤回後，原照片不能再送出。以獲准版本明確重新同意後可傳新照片。重播舊期間的撤回仍只影響舊期間。切回先前的一般版本後，新期間仍應能由額外撤回清單內的組建撤回；重啟後再查，已封存的標記與目前媒體物件的版本應一致。
4. 將 iOS 組建、兩份版本清單、研究服務映像摘要、服務修訂、合成測試結果列入交付紀錄。已交付組建若未納入任何有效清單，或手機遺失原安裝身分，應沿用資料處理支援流程。現場驗收須另行取得部署與合成操作授權。

撤回收據對應的是該研究服務可核對的目前媒體。歷史版本、其他服務及備份的處置需要各自的證據。這項版本判定不會變更個人服務或訂閱權限。
