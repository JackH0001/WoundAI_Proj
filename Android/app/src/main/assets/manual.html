WoundAI 使用說明書

傷口量測與標註 App ・ 臨床人員操作指南

先讀這一段

本系統是輔助工具，不是診斷器材。面積、組織比例、PUSH 分數都需要醫師確認後才有意義。 AI 給出的初始輪廓經常需要修正——那不是故障，那正是設計上要醫師介入的地方。

病患姓名與病歷號永遠不會離開這支手機。送到雲端的只有去識別代碼 （WD- 開頭）、傷口輪廓與影像。這是同意書對病患的承諾。

一、整體流程一眼看懂

兩條路都到得了「送出標註」

  1. 當場送：量測 → 修邊 → 輸入滲液 → 直接按「醫師確認・送出標註」
  2. 事後補送：先存入時間軸 → 日後從時間軸點該筆 → 「重新修邊」→「補送訓練標註」
    病患當下還沒簽②訓練同意時走這條。後端靠影像編號找得到當初的照片，不必重測。

二、主畫面五個入口

按鈕什麼時候按
個案（病患・同意書・個案傷口・量測） 臨床量測一律從這裡進。紀錄才會歸戶到正確的傷口，代碼也才穩定（回診沿用同一組）。
最近就診 快速找到最近量測過的個案，不必從病患列表一層層點進去。
快速量測（範例／模擬圖・不綁個案） 練習操作、測試貼紙擺法。紀錄不屬於任何個案，不計入臨床收案進度。
設定（後端連線・帳號・佇列健康度） 填後端位址與帳號密碼、按 連線測試 確認、進主控台。
使用說明書（依角色分頁・可離線查閱） 就是你現在看的這一份。不需要網路。

四、醫師：修邊與送出標註

只有你能做兩件事：完成修邊（＝「醫師已驗證」）與送出訓練標註。 整個系統的訓練資料品質建立在你的修邊上——AI 之後學到的東西，就是你畫的東西。

3-1 修邊畫面按鍵圖解

控制項作用
邊界＋把筆刷經過的地方加進傷口範圍。這是進入畫面時的預設工具。 新加的像素會自動帶上 AI 的組織判斷，不會整片變同一色。
邊界－把筆刷經過的地方移出傷口範圍。
移動只平移，不會畫到東西。單指拖曳畫面。
組織🖌改組織分類。只會改傷口範圍內的像素，塗到外面不會有作用。 下方五個組織按鈕永遠都在（顏色就是塗上去的實際疊色），選了這個工具之後才能按。 預設選中的是「腐肉」。
按住看原圖按住時暫時隱藏組織顏色看原始照片，手指放開立刻回來。 按住期間畫筆完全停用（另一隻手也畫不上去），畫面大小不會變動。
－ ＋縮小／放大。也可以用兩指捏合。
ROI把畫面拉近到目前的傷口範圍。
全圖退回看整張照片。
↺ ↩復原／重做。畫到框邊讓範圍自動擴張時，這兩個會被清空——擴張前請先確認。
取消整批放棄。按取消不算完成修邊，之後不能送訓練標註。
完成修邊存下你的判斷。傷口範圍是空的時候按不下去。

3-2 組織顏色對照

顏色組織為什麼是這個顏色
綠肉芽 紅色的互補色。疊在紅色肉芽上對比最大，而且不會被誤認成組織本身的顏色。
琥珀腐肉接近腐肉本身的黃。
深紫壞死不用純黑——純黑會與傷口陰影混淆。
粉上皮接近新生上皮的淡粉。
灰其他 判不出類別的：肌腱、異物、血水、遮蔽物、反光。
亮青線傷口邊界 不是組織。關掉組織圖層時它仍然在，所以你永遠看得見自己在畫什麼。

「其他」不是逃生門，但也不要硬塞

畫面出現「有 X% 判不出類別」時，請用「組織🖌 → 其他」把那一塊確認起來， 或改標成正確的組織。把肌腱硬塞進「壞死」會把錯誤的定義教給模型； 標成「其他」是誠實的，那一塊會照原樣進訓練集。

3-3 完成修邊之後會怎樣

  • 畫面出現 ✓ 已完成醫師修邊確認 — 可送訓練標註
  • 面積會用你畫的範圍重新計算（尺度來自 ArUco 貼紙，不依賴 AI 的初始面積）
  • 你沒動邊界時，面積不會變動——那是刻意的，避免每進出一次就漂移一點

只改組織、沒動邊界，也要按「完成修邊」

組織分區與傷口邊界是兩份獨立的資料。只改了組織一樣要按「完成修邊」才會存下來， 按「取消」的話組織標註也會一起丟掉。

3-4 送出訓練標註

按 醫師確認・送出標註 → 再訓練佇列。這顆按鈕要滿足全部條件才出現且可按：

  1. 已輸入滲液量
  2. 已完成修邊確認（或已存入時間軸）
  3. 臨床樣本必須已選個案傷口
  4. 該病患有有效的②訓練同意

3-5 事後補送（病患當下還沒簽②訓練同意時）

  1. 個案頁 →「查看此傷口時間軸」→ 點該筆紀錄
  2. 重新修邊（載回原影像與輪廓） —— 影像與輪廓都會載回來，不必重測
  3. 修完按「完成修邊」
  4. 補送訓練標註 → 再訓練佇列

從時間軸補送時，確認視窗會列出每一個要離開手機的欄位

包含代碼、影像編號、輪廓點數、面積、滲液、樣本來源，以及組織遮罩的狀態：

  • ✓ 含醫師修正 N 像素 — 會進入組織分割訓練集
  • △ 會送出，但標記為「未經醫師修正」 — 不會進訓練集。未修正的遮罩是 AI 自己的輸出， 拿去訓練等於自我確認。
  • ✗ 不送（本筆沒有修邊柵格） — 請先按「重新修邊」

看到「已在佇列（去重）」的意思

代表這一筆與雲端既有樣本的影像、傷口輪廓、組織遮罩三者完全相同。 如果你剛才確實有修改卻看到這則訊息，請確認是不是按了「取消」而不是「完成修邊」。

五、護理師：建檔、同意書、量測、存病歷

你能做整條流程的前半段，但修邊不會產生「醫師已驗證」，也不能送訓練標註。 這是後端強制的，不是畫面問題。你的量測與存檔一樣完整有效。

4-1 建立病患與個案傷口

  1. 主畫面 → 個案（病患・同意書・個案傷口・量測）
  2. 填姓名與病歷號 → ＋新增病患
    這兩項只存在這支手機，加密保存，永遠不會上雲。
  3. 選病患 → 簽署同意書（見下一節）
  4. 填部位（如 薦骨/右足跟）與類型（如 壓瘡/糖尿病足）→ ＋新增個案傷口
    系統會配一組 WD- 代碼。回診請沿用同一個傷口，時間軸才接得起來。

4-2 兩種同意，用途完全不同

① 照護同意② 研究／訓練同意
必填？必填選填，可隨時撤回
沒有它就不能建傷口、量測、存病歷送訓練標註
用途本人傷口照護之量測與紀錄去識別後用於演算法改良

簽名是必要的——沒有簽名按不下「確認簽署」。②勾不勾都可以簽送。

兩個項目下方都有可展開的 詳細說明，內容包含：拍什麼、存在哪、誰看得到、 保留多久、用途限制、如何撤回、以及撤回的實際效果。 ②訓練同意的說明標示「請務必閱讀」，請與病患一起看過再勾選。

撤回訓練同意：本機立刻生效，雲端會自動同步

按下 撤回訓練同意 之後：

  1. 本機立刻生效——這是病患的權利，不會因為當下沒網路而被拒絕
  2. App 隨即向雲端撤回，成功的話顯示
    「✅ 已撤回訓練同意，雲端也已排除…這些代碼的影像已移入隔離區，不再進入任何訓練集。」

如果當下沒有網路或後端連不上，畫面會誠實地說：

「⚠ 本機已撤回，但雲端尚未完成…這些代碼的資料目前仍在雲端訓練佇列中。」

這些未完成的撤回會持續顯示在個案管理頁最上方，直到真的完成為止。 下次連上後端時 App 會自動重試，也可以按「立即重試」。 一直失敗的話請找管理者到主控台手動撤回。

要對病患誠實說明的一件事

撤回會讓資料立即退出未來的訓練，但如果在撤回之前系統已經用那些資料 訓練過某個版本的模型，那個已完成的模型無法「忘記」學過的東西。 這是這類技術的性質，同意書的「詳細說明」裡已寫明，簽署前請確認病患理解。

4-3 量測

  1. 選傷口 → 開始量測
  2. 拍照 / 相簿 / 檔案 三選一
  3. 等 AI 跑完，看量測結果卡片
  4. 輸入滲液量（0 無／1 少量／2 中量／3 大量）——不輸入的話後面兩顆按鈕都是灰的
  5. 存入個案時間軸

拍照三個要點

  • ArUco 校正貼紙要完整入鏡，而且不要有反光或摺到——沒有它就量不出真實尺寸
  • 盡量正對傷口拍。斜拍會讓面積偏低
  • 貼紙與傷口盡量在同一個平面。貼在隆起處會讓比例算錯

六、助理／技術員：量測與檢視

你可以量測與檢視，但不能建病患、不能存入時間軸、不能送訓練標註。

你的典型流程

  1. 請護理師或醫師先建好病患與傷口、簽好同意書
  2. 主畫面 → 個案（…） → 選病患 → 選傷口 → 開始量測
  3. 拍照 → 等 AI 跑完 → 輸入滲液量
  4. 請護理師或醫師接手按「存入個案時間軸」

按了「存入個案時間軸」會看到什麼

「⚠️ 角色「助理」不得存入個案時間軸。請由護理師或醫師完成存檔（量測結果不會遺失）。」

量測結果不會不見，換人登入或請對方在這台手機上接手即可。

你可以自由使用的部分

主畫面的 快速量測（範例／模擬圖・不綁個案） 對所有角色開放。 用它練習操作、測試貼紙擺法、確認相機角度都不會影響臨床資料。

七、工程師／管理者

你沒有臨床權限：不能建病患、不能做臨床量測、不能存病歷。這是刻意的設計。

6-1 設定頁的入口

按鈕誰看得到用途
開啟「我的送件」（可自行標記排除誤送）醫師・護理師・工程師・管理者 看自己送出的每一筆、狀態、組織／深度／品質欄位，並可排除誤送
開啟管理主控台（帳號管理・稽核・系統狀態）管理者 Dashboard／我的送件／系統狀態／稽核軌跡／帳號管理
開啟主控台（稽核・系統狀態・佇列）工程師同上，但沒有帳號管理
開啟 GCP 雲端主控台（需 Google 帳號授權）工程師・管理者 雲端基礎設施。臨床角色一律不給——那裡看得到原始傷口影像。

主控台以一次性登入碼自動登入（60 秒有效、用過即失效，且放在網址的 # 之後， 那一段不會送到伺服器，因此不會留在雲端日誌裡）。

6-2 系統狀態要看的三件事

項目紅了代表
ONNX Runtime／分割模型退回 HSV 色彩分割。服務仍回 200、面積仍有數字，但不可作臨床用途。
色準校正白平衡退回 gray-world，紅色被系統性壓抑，肉芽會被低估。同樣不會報錯。
儲存後端不是 GCS 的話，佇列與影像會在實例回收時無聲消失。

「部署身分」區塊顯示雲端跑的 git commit，與本機 git rev-parse --short HEAD 比對即可確認部署是否生效。

6-3 帳號原則

  • 帳號用編號（dr01、ns01…）不用姓氏——帳號會永久留在稽核軌跡裡
  • 帳號只停用、不刪除——稽核軌跡引用著那些識別碼
  • 密碼絕不寫進程式或版控

詳細操作見 docs/admin_operations.md。

八、常見狀況與對策

畫面顯示意思與對策
⚠ 請先選擇個案傷口臨床量測一定要先綁傷口，紀錄才歸得了戶。回個案頁選一個。
⚠ 此病患尚未取得①照護同意（或已撤回），不得進行量測 回個案頁 →「簽署同意書」，①照護同意是必填。
⚠ 請先輸入滲液量，才能進行「修邊」或「存入時間軸」 點一下 0／1／2／3 其中一個。PUSH 分數需要它。
尚未完成醫師修邊確認：此結果為 AI 原始輸出 可以存病歷，但不能送訓練標註。請醫師按「醫師確認・修邊」並完成（按取消不算）。
⚠ AI 未偵測到傷口 用「邊界＋」從零塗抹即可。ArUco 尺度仍然有效，面積照樣精確。
⚠ AI 沒偵測到傷口，但影像中有明顯的印刷色塊 這多半是印刷模擬圖。請到快速量測把來源改選「模擬圖」，會改走色彩分割。
⚠ 這張影像後端先前已收過（逐位元相同） 回診照片不可能與上次完全一樣，這多半是先前用過的範例圖。不要存入病歷， 否則會計入臨床收案進度，還會讓癒合曲線變成兩張不同傷口相比。
ℹ 後端可能處於休眠 雲端閒置會自動縮容。第一次量測約需 10–30 秒喚醒，之後正常。
⚠️ 連不到後端 到「設定」確認位址；真機不能用 10.0.2.2（那是模擬器專用）。
⚠️ 連得到後端但帳密不正確位址沒問題，到「設定」重新輸入帳號密碼。
⚠ 影像與輪廓座標空間不符，已停用重新修邊 這筆是舊格式的紀錄。面積數值仍可作病歷保留，但要重新量測一次才能再修邊。

九、隱私與資料界線

永遠留在這支手機

病患姓名、病歷號、同意書簽名影像。這些以手機的安全金鑰加密保存。

會離開手機（僅在②訓練同意有效時）

去識別代碼 WD-xxxxxxxx、傷口影像、輪廓、組織遮罩、面積、滲液、樣本來源、機型。 沒有姓名、沒有病歷號。資料存放在台灣境內（asia-east1）。

臨床影像不會寫進手機相簿

只有「範例」與「模擬圖」會匯出到相簿的 WoundAI_驗證 資料夾。
